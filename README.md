# PLAYVERSE – Mini Games

Eine kostenlose, responsive Spieleplattform, die ohne Build-Schritt auf **GitHub Pages** läuft.

## Online spielen

Nach Aktivierung von GitHub Pages ist die Seite unter
https://skibidifusion200810-star.github.io/minigames/
erreichbar.

## GitHub Pages einrichten

1. Repository → **Settings** → **Pages**.
2. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
3. Branch **main** und Ordner **/(root)** einstellen.
4. **Save** klicken; anschließend die veröffentlichte Pages-Adresse öffnen.

## Spiele

- Mordakte: Villa Falken – interaktiver Kriminalfall mit sechs untersuchbaren Beweisen, vier Verdächtigen und Auflösung
- Tic Tac Toe – zwei Spieler an einem Gerät
- Vier Gewinnt – zwei Spieler an einem Gerät
- Quiz Arena
- Memory Flip
- Reaction Rush
- Zahlensuche
- Schere Stein Papier

## Technische Hinweise

Alle Spiele sind reine HTML/CSS/JavaScript-Anwendungen und benötigen weder Node.js noch einen Server. Die Spiele funktionieren auf Mobilgeräten und Desktop.

**Wichtig:** Diese Version bietet lokale Spiele und Solospiele. Echte Online-Lobbys mit Lobby-Codes, Nutzerkonten, Freundesliste, globaler Chat und Echtzeit-Multiplayer benötigen einen externen Backend-Dienst wie Supabase oder Firebase. GitHub Pages allein kann keine serverseitigen Multiplayer-Sessions oder sicheren Accounts bereitstellen. Entsprechende Online-Funktionen werden deshalb in dieser Version **nicht** vorgetäuscht.
